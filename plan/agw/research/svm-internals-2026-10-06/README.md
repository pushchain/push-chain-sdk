## Implemented

- [SVM terms codec](../../../../packages/core/src/lib/agentic/codec/svm-terms.ts): exact version-4 body tuple, ordered AssetCaps, program/discriminator rules, account/data pins, shape/bounds, ambiguous prefixes, forbidden programs, raw EQ alignment, little-endian integer widths and ratio constraints.
- [Value-account derivation](../../../../packages/core/src/lib/agentic/codec/svm-accounts.ts): CEA PDA uses the wallet's 20 bytes plus the selected registry gateway; legacy SPL/Token-2022 ATAs; input/output mint coverage, deduplication and the 16-account bound. The resolved-asset context contributes an ATA for every listed SPL mint; native SOL is protected by the CEA itself. Gateway is caller-resolved, not a hard-coded devnet program.
- [Payload checks](../../../../packages/core/src/lib/agentic/execution/svm-payload.ts): reuses the existing node encoder and parses BE counts/lengths, exact consumption, execute ID, recipient/program identity, account positions, protected-account aliasing and all four data-pin modes. Writable bytes are preserved diagnostically; URP deliberately does not enforce them.
- [Internal outbound action](../../../../packages/core/src/lib/agentic/execution/svm-outbound.ts): program recipient, wallet refund, per-token current spend/caps, u64 request amounts and quoted PC budget. Takes a resolved config snapshot; on-chain URP remains final authority.
- SvmConfigRead is available internally. Public exports, Rule union and UNIVERSAL_SVM_RULES capability remain unchanged/gated while the public mapping is unsettled.

```sh
node node_modules/jest/bin/jest.js --config packages/core/jest.config.ts --runInBand --testPathPattern=agentic

```

run-forge.sh requires the isolated e8db748 build prepared by scripts/agw-local/prepare.sh (or AGW_LOCAL_DIR). The Anvil integration suite is packages/core/__agw-local__/svm-internals.spec.ts and must be rerun when localhost access is available.
