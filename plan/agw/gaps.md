## Cross-cutting requirements

- expectedCEA is SDK-derived context: derive the AGW destination account, commit it in every universal rule, display it and monitor derivation drift. Do not use the signer CEA or an arbitrary pasted address.
- Checkpoint consumers compare counts, not only blocks. Replacement adds five ticks. Pre-existing allowance pulls can change balances without a new checkpoint, so evaluator policy needs explicit scope.
- create deploys/grants only; funding and approvals are separate. AGENTIC-TX-103 is removed.
- Assets[]/maxGasPerCall require new matching artifacts. Proposed asset maxTotal zero is unlimited; native defaults are separate. Per-token Spent and stale-spend assertions remain unresolved.
- Binder is dropped for v1. Historical hook cleanup text is not authorization to add it.
- Preserve explicit zero/omission semantics, supported native arrays and deterministic duplicate-rule behavior; do not silently alter policy failure timing.
