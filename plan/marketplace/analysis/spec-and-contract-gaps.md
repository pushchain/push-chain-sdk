October 20, 2026. **P0** blocks automatic-evaluation integration; **P1** affects a promised behavior or safe transaction construction; **P2** is a bounded SDK design/detail. A finding is not automatically a request for a contract change. Existing deployed behavior can support a smaller explicit first release.
